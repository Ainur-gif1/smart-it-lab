# SMART IT LAB — виртуальная IT-лаборатория с AI-наставником

Образовательный веб-симулятор для системы технического и профессионального образования.
Учащийся собирает виртуальный ПК, создаёт простые IoT-системы на ESP32 и получает
контекстные подсказки от AI Mentor — без реального оборудования и без риска его повредить.

Проект — обычный статический сайт: **HTML5 + CSS3 + Vanilla JavaScript**.
Не нужны backend, база данных, npm, сборщики, платные API и интернет.

## Возможности

| Раздел | Что умеет |
|---|---|
| **Главная** | Описание, карточки лабораторий, статистика из localStorage (пройдено, попытки, средний результат) |
| **PC Builder** | 21 комплектующее, 7 слотов, установка кликом / кнопкой / drag & drop, проверка совместимости, имитация POST, 3 задания |
| **IoT Lab** | ESP32 и Arduino-совместимый контроллер, 3 датчика, 4 исполнительных устройства, назначение GPIO, проверка схемы, симуляция, 3 проекта |
| **AI Mentor** | Локальная экспертная система: «Что не так?», «Подскажи следующий шаг», «Объясни компонент», «Почему это несовместимо?» |
| **Обучение / Экзамен** | В экзамене подсказки и подробности ошибок скрыты до завершения |
| **Мой прогресс** | Лучший балл, попытки, дата последней попытки; кнопка «Сбросить прогресс» |
| **Режим преподавателя** | Все задания, компетенции, макс. балл, результаты, ошибки, подсказки; экспорт в JSON и CSV |
| **Демонстрация** | Готовые стартовые сценарии для показа комиссии (часть шагов делается вручную) |
| **RU / KZ** | Переключение языка всего интерфейса, выбор запоминается |

### Проверки PC Builder
- сокет CPU ↔ материнская плата (AM4 / LGA1700);
- тип памяти (DDR4 / DDR5);
- охлаждение: отвод тепла кулера ≥ TDP процессора;
- мощность БП: потребление × 1,1 (запас 10 %), рекомендуемый БП подбирается автоматически;
- наличие видеовыхода (видеокарта или встроенная графика);
- все обязательные компоненты установлены;
- условия конкретного задания (бюджет, видеокарта, объём RAM, число ядер).

### Проверки IoT Lab
- нужен ESP32 (у Arduino-совместимой платы нет Wi-Fi);
- все компоненты проекта на плате и подключены к GPIO;
- GPIO 34/35 — только вход (нельзя подключать LED, вентилятор, зуммер);
- аналоговый датчик освещённости — только на вход АЦП (GPIO 32–35);
- один GPIO — одно устройство;
- лишние компоненты — предупреждение (не ошибка).

### Система баллов (максимум 100)
- **PC Builder:** обязательные компоненты 20, сокет 10, память 8, охлаждение 7, питание 15, условия задания 20, успешный запуск 20.
- **IoT Lab:** контроллер 15, компоненты 25, правильные GPIO 30, проверено состояние ON 15, OFF 15.
- Штрафы: ошибка −5 (установка, создавшая несовместимость; неудачный запуск; проваленная проверка схемы), подсказка AI −3. «Объясни компонент» — бесплатно.

достаточно дописать объект в массив `COMPONENTS` или `TASKS`.

## Как запустить

### Вариант 1 — просто открыть файл
Дважды щёлкните `index.html`. Сайт написан на обычных (не модульных) скриптах,
поэтому работает даже с адреса `file://` и без интернета.

Если браузер всё-таки что-то блокирует (например, строгие корпоративные настройки),
запустите локальный сервер из папки проекта:

```bash
python -m http.server 8000
```
(на macOS/Linux может понадобиться `python3`). Затем откройте http://localhost:8000

### Вариант 2 — VS Code Live Server
1. Откройте папку `SMART-IT-LAB` в VS Code.
2. Установите расширение **Live Server** (автор Ritwick Dey).
3. Правой кнопкой по `index.html` → **Open with Live Server**.

## Как опубликовать сайт через GitHub Pages (бесплатно)

1. Зайдите на https://github.com и войдите в аккаунт.
2. Нажмите **New repository**. Название, например, `smart-it-lab`. Тип — **Public**
   (GitHub Pages для бесплатного аккаунта работает с публичными репозиториями).
   Нажмите **Create repository**.
3. Загрузите файлы:
   - на странице репозитория нажмите **uploading an existing file**
     (или **Add file → Upload files**);
   - перетащите **содержимое** папки `SMART-IT-LAB` (не саму папку!):
     `index.html`, папки `css`, `js`, `assets`, файлы `README.md`, `PROJECT_PASSPORT.md`, `LICENSE`, `.nojekyll`;
   - `index.html` должен оказаться в корне репозитория;
   - нажмите **Commit changes**.

   > Файл `.nojekyll` скрытый. Если проводник его не показывает — ничего страшного,
   > сайт работает и без него.

   Через командную строку (если установлен Git):
   ```bash
   cd SMART-IT-LAB
   git init
   git add .
   git commit -m "SMART IT LAB"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/smart-it-lab.git
   git push -u origin main
   ```
4. Откройте **Settings** репозитория.
5. В меню слева выберите **Pages**.
6. В блоке **Build and deployment → Source** выберите **Deploy from a branch**.
7. В поле **Branch** выберите **main**.
8. Папку оставьте **/ (root)**.
9. Нажмите **Save**.
10. Через 1–3 минуты обновите страницу — вверху появится адрес вида
    `https://ВАШ_ЛОГИН.github.io/smart-it-lab/`. Это и есть ссылка на сайт.

Все пути в проекте относительные (`css/style.css`, `js/app.js`), поэтому сайт
корректно работает из подпапки GitHub Pages.

**Обновление сайта:** загрузите изменённые файлы в репозиторий ещё раз (Add file → Upload files → Commit).
GitHub Pages пересоберёт сайт автоматически за 1–2 минуты.

## Подключение настоящего AI (необязательно)

По умолчанию AI Mentor — **локальная экспертная система**: правила в `js/ai-mentor.js`
анализируют задание, установленные компоненты, ошибки совместимости и GPIO и формируют ответ.
Ответы не случайные и всегда зависят от состояния симулятора. Интернет не нужен.

Чтобы подключить большую языковую модель (LLM), укажите в `js/config.js` адрес **своего** backend:

```js
const AI_ENDPOINT = "https://ваш-сервер.example/api/mentor";
```

Сайт отправит `POST` с JSON:
```json
{
  "intent": "wrong | next | explain | why",
  "lab": "pc | iot",
  "lang": "ru | kz",
  "context": { "...": "краткое описание состояния лаборатории без персональных данных" },
  "localAnswer": "ответ локальной экспертной системы"
}
```
и ожидает ответ `{ "reply": "текст подсказки" }`. Если сервер недоступен или отвечает ошибкой,
показывается локальный ответ — сайт продолжает работать.

### Почему API-ключ нельзя вставлять в JavaScript сайта
GitHub Pages раздаёт файлы сайта **всем посетителям как есть**. Любой может открыть
«Просмотр кода» или DevTools и увидеть ключ. Дальше чужие люди могут тратить ваш платный
баланс, а провайдер может заблокировать ключ. Поэтому:

- ключ хранится **только на сервере** (переменная окружения backend);
- сайт обращается к вашему серверу, а сервер — к API модели;
- на сервере стоит ограничение частоты запросов и проверка домена (CORS);
- в `config.js` хранится только адрес сервера, а не ключ.

Минимальный пример такого сервера (Node.js 18+, Express) — разместить на любом хостинге,
где можно хранить переменные окружения:

```js
// server.js — НЕ кладите этот файл на GitHub Pages
import express from "express";
const app = express();
app.use(express.json({ limit: "20kb" }));
app.use((req, res, next) => {
  res.set("Access-Control-Allow-Origin", "https://ВАШ_ЛОГИН.github.io");
  res.set("Access-Control-Allow-Headers", "Content-Type");
  if (req.method === "OPTIONS") return res.sendStatus(204);
  next();
});
app.post("/api/mentor", async (req, res) => {
  const { intent, lang, context, localAnswer } = req.body;
  const prompt = `Ты наставник по IT для студентов колледжа. Язык ответа: ${lang}.
Вопрос ученика: ${intent}. Состояние лаборатории: ${JSON.stringify(context)}.
Подсказка экспертной системы: ${localAnswer}. Ответь кратко (3–5 предложений), объясни причину и следующий шаг.`;
  // Здесь вызов API выбранной модели с ключом из process.env.LLM_API_KEY
  const reply = await callYourLlm(prompt);
  res.json({ reply });
});
app.listen(process.env.PORT || 3000);
```

## Безопасность и данные
- Регистрация не нужна, ФИО не собираются.
- Прогресс хранится только в `localStorage` этого браузера (ключ `smartitlab.progress.v1`).
- Поле «Код учащегося» в режиме преподавателя необязательно и предназначено для псевдонима/номера, не для ФИО.
- В проекте **нет** API-ключей и секретов. Проверить: поиск по файлам строк `key`, `token`, `secret`.
- AI — помощник, а не замена преподавателя; ответы — учебные рекомендации.

## Как добавить язык
1. В `js/translations.js` скопируйте объект `ru`, назовите, например, `en` и переведите строки.
2. В `index.html` добавьте кнопку: `<button type="button" data-lang="en" aria-pressed="false">EN</button>`.
