## 🇰🇿 Қазақша

### Жоба туралы
**SMART IT LAB** — техникалық және кәсіптік білім беру (ТжКБ) жүйесіне арналған білім беру веб-симуляторы. Білім алушы нақты жабдықсыз:

- компьютер құрамдас бөліктерінен **виртуалды ДК жинайды**, олардың үйлесімділігін тексеріп, POST іске қосады;
- ESP32 негізінде **қарапайым IoT-жүйелер жасайды**: датчиктер мен құрылғыларды GPIO-ға қосып, жұмысын симуляциялайды;
- **AI Mentor** тәлімгерінен кеңес алады: ол қатені түсіндіреді, себебін айтады және келесі қадамды ұсынады.

Қате жинау нақты жабдықты бүлдірмейді, сондықтан оқушы алдымен қауіпсіз цифрлық ортада үйренеді, содан кейін нақты жабдыққа көшеді.

### Жасанды интеллект қалай қолданылады

**Шынайы түрде:** негізгі нұсқа — браузерде жұмыс істейтін жергілікті сараптамалық жүйе (диагностика ережелері). Ол интернетсіз жұмыс істейді және деректерді сыртқы сервистерге жібермейді. ## 🇷🇺 Русский

### О проекте
**SMART IT LAB** — образовательный веб-симулятор для системы технического и профессионального образования (ТиПО). Без реального оборудования учащийся:

- **собирает виртуальный ПК** из комплектующих, проверяет их совместимость и запускает POST;
- **создаёт простые IoT-системы** на ESP32: подключает датчики и устройства к GPIO и моделирует их работу;
- получает подсказки от **AI Mentor**: наставник объясняет ошибку, называет её причину и предлагает следующий шаг.

Неправильная сборка не повредит реальное оборудование. Учащийся сначала тренируется в безопасной цифровой среде, а затем переходит к реальной технике.

**Баллы (максимум 100):** ошибка −5, AI-подсказка −3, объяснение компонента бесплатно, бонус за успешный запуск.

### Как используется искусственный интеллект
AI Mentor анализирует действия учащегося, определяет ошибки, формирует персональные подсказки, объясняет технические понятия и предлагает следующий шаг. Подсказки не случайные: они зависят от фактического состояния симулятора (задание, установленные компоненты, GPIO, результаты проверки).

**Честно о реализации:** базовая версия — локальная экспертная система (правила диагностики), которая работает в браузере. Она не требует интернета и не отправляет данные во внешние сервисы. При необходимости можно подключить большую языковую модель (LLM) через защищённый backend (параметр `AI_ENDPOINT` в `js/config.js`).

## Практическое занятие / Практикалық сабақ

Откройте **«Практическое занятие»** (`#practice`) и выберите одну из шести работ.
Каждая работа рассчитана на 45 минут: инструктаж — 5, требования — 5,
выполнение — 25, отчёт и защита — 10 минут. Есть цель, инструкция,
контрольные значения для IoT и вопросы для защиты на русском и казахском языках.

1. Укажите код студента/группы без ФИО.
2. Откройте выбранный симулятор, выполните работу и сохраните результат
   штатной проверкой/завершением лаборатории. В режиме экзамена IoT нажмите
   «Завершить экзамен».
3. Вернитесь в практическое занятие и заполните наблюдения, исправление
   ошибок и вывод. Черновики разделены по заданиям и сохраняются в браузере.
4. Скачайте JSON-отчёт или используйте «Печать / PDF». Длинные ответы
   печатаются обычным текстом, без обрезки внутри textarea.
5. В режиме преподавателя откройте полученные JSON-отчёты для общей таблицы
   (до 100 файлов, каждый до 1 MB). Файлы обрабатываются только на устройстве.

Самопроверка не начисляет баллы. Балл симулятора и отчёт — отдельные результаты;
оценку за защиту выставляет преподаватель. В отчёт включается последняя
сохранённая попытка выбранного задания, в том числе попытка до текущего урока:
обязательно сверяйте её дату. Импортированные отчёты не сохраняются после
перезагрузки страницы. Студенческие JSON можно редактировать; это инструмент
