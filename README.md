# SMART IT LAB Classroom

Қазақша практикалық зертхана. Бастапқы SMART IT LAB негізінде бөлек әзірленген нұсқа. Сайт IoT зертханасына бірден ашылады. Негізгі жарияланған GitHub Pages сайтын өзгертпейді.

## Іске қосу

1. ZIP-ті толық шығарыңыз.
2. Компьютерде Python 3 бар болса, жоба папкасында `python start_server.py` іске қосыңыз. Кейбір жүйеде команда `python3 start_server.py` болады.
3. Терминалда көрсетілген `http://127.0.0.1:8000/#iot` мекенжайын браузерде ашыңыз. Терминалды жаппаңыз.
4. Тоқтату: Ctrl+C. 8000 порты бос болмаса, `python start_server.py --port 8001` пайдаланыңыз. Бір портты тұрақты пайдаланыңыз: порт ауысса, браузердегі нәтижелер басқа сақтау аймағында болады.

Негізгі зертханаларға Интернет пен сыртқы API қажет емес. Барлық скрипт, CSS және SVG жергілікті. Қосымша іске қосу тәсілі: `index.html` файлын тікелей ашу. `file://` режиміндегі сақтау тәртібі браузерге байланысты, сондықтан тұрақты localhost мекенжайы ұсынылады.

**Тексеру шегі:** осы ортада браузер preview қызметі қолжетімсіз. Нақты браузердің `file://` және localhost режимдеріндегі жұмысы, басып шығару, мобильді көрініс пен консолі толық тексерілген деп мәлімделмейді. Жергілікті JavaScript интеграциялық сынақтары нақты браузер сынағын алмастырмайды.

## Ақылды жарықтандыру

1. Қаласаңыз, студент немесе топ кодын жазыңыз. Аты-жөні қажет емес.
2. ESP32, жарық датчигі және LED қосыңыз.
3. Датчикке GPIO34, LED-ке GPIO12 таңдаңыз.
4. «Схеманы тексеру», кейін «Симуляцияны іске қосу» басыңыз. Іске қосу батырмасы да алдымен схеманы тексереді.
5. 290 лк кезінде LED ON, 300 және 310 лк кезінде OFF болуы керек.
6. «Тоқтату» симуляцияны тоқтатады. «Симуляцияны іске қосу» жалғастырады. «Қайта іске қосу» сенсор мәні мен бақылауларын бастапқы күйге қайтарады.
7. Сақталған нәтижеден кейін симуляцияны қайта іске қосу жаңа әрекет ашады. Схеманы өзгерту тексеруді және симуляцияны жояды.
8. Оқу режимінде ON және OFF күйлері бақыланғанда нәтиже бір рет сақталады. Емтиханда «Емтиханды аяқтау» батырмасы нәтижені сақтайды.

Температура: ESP32 + DHT22 GPIO4 + желдеткіш GPIO26. 27 және 28 °C OFF, 29 °C ON.
Қозғалыс: ESP32 + PIR GPIO14 + буззер GPIO25. Қозғалыс жоқ OFF, бар ON.

Оқу үлгісі нақты электрлік құбылыстарды толық модельдемейді. LED резисторы, қорек, ортақ жер және мотор драйвері нақты жабдықта бөлек тексеріледі. DHT22 екі бағытты цифрлық байланысқа мұқтаж, сондықтан ESP32 input-only пиндері оған жарамсыз. Код мысалы ESP32-ге тікелей жүктеуге дайын бағдарлама емес.

## Нәтижелер және есеп

«Менің прогресім» әр әрекетті бөлек көрсетеді: код, тапсырма, күн, режим, ұпай, уақыт, қате және көмек саны. Әр жазбада тексеру нәтижесі бар. Бір әрекетті қайта іске қосудың өзі қайталама жазба жасамайды. ПК-да құрастырманы өзгерту немесе қайта бастау жаңа әрекет ашады.

Журналдағы «Жұмыс есебі» арқылы дәлелді, түзетуді және қорытындыны жазыңыз. Жоба автоматты сақталады. Осы есепті JSON түрінде жүктеуге немесе басып шығаруға болады.

Оқытушы режимі жеке JSON/CSV экспорттайды. CSV ұяшықтарында формулалық мәтін бейтараптандырылады. Бірнеше студенттің JSON файлдарын импорттауға болады: 50 файл, әрқайсысы 2 MB, бір файлда 2000 жазбаға дейін, ортақ импортта 5000 жазбаға дейін. Қате файл және қайшы ID қабылданбайды. Дәл қайталанған жазба есепке қосылмайды. Импорт өз прогресіңізді өзгертпейді. Ортақ кестені JSON етіп жүктеп алыңыз: ол бет жабылғанда жоғалады.

Импорт тек `format: "smartitlab-classroom-v2"` форматын қабылдайды. Бастапқы сайттың жиынтық v1 экспортына автоматты түрлендіру жоқ. Бір студенттің есебі кейін жаңартылып, сол ID-мен қайта импортталса, қайшылық ретінде қабылданбайды. Қай нұсқасын пайдалану керегін оқытушы шешеді.

Нәтижелер осы браузер мен origin ішінде сақталады. Бұрынғы SMART IT LAB деректері автоматты көшірілмейді. Браузер сақтауға тыйым салса, нәтижелер ағымдағы бетте сақталып, ескерту көрсетіледі. Бетті жаппас бұрын экспорттаңыз. Файлдар мен localStorage өзгертілуі мүмкін: бұл қорғалған емтихан жүйесі емес.

## Көмекші және емтихан

Контекстік көмекші - браузердегі ережелік сараптамалық жүйе. Ол ағымдағы компоненттер мен тексеруге сүйенеді. Бұл нұсқада сыртқы тілдік модель қолданылмайды, `AI_ENDPOINT` бос. Құпия API кілтін браузер кодына салмаңыз. Болашақ интеграция сервер арқылы жасалуы керек.

Емтиханда көмекші жауаптары және дайын қадамдар жабық. Бағалаудан кейін қате мәліметтері көрсетіледі. Сабақтағы түсіндіру сапасын оқытушы бөлек бағалайды.

## Әзірлеушіге

Жоба framework және сыртқы кітапхана қолданбайды. Браузер JavaScript-і қарапайым скрипттермен жүктеледі.

Тест: `node tests/classroom.test.cjs --write` (Node.js 18+).
Жергілікті HTTP серверінің smoke test: `python tests/server.test.py`.
Static build: `python scripts/build_static.py`.
Offline ZIP: `python scripts/package_offline.py --output ../SMART_IT_LAB_Classroom.zip`.

Автоматты сынақтар жеңіл DOM моделімен нақты қолданба функцияларын іске қосады. DOM моделі layout, accessibility, басып шығару, браузерлік жүктеу және шынайы pointer әрекетін тексермейді. Студенттік апробация жүргізілген жоқ. Жалған статистика қолданылмайды.
