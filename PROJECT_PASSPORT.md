# Паспорт проекта

## Название
**SMART IT LAB — виртуальная IT-лаборатория с AI-наставником**

## Проблема
Колледжам и школам не всегда хватает компьютерных комплектующих, IoT-наборов, плат
Arduino/ESP32 и датчиков. Оборудование дорогое, изнашивается, а начинающий ученик может
случайно повредить его: перепутать сокет, подать питание не на тот вывод, подключить
нагрузку к входному пину. Из-за этого практики меньше, чем нужно, и первые ошибки
обходятся дорого.

## Актуальность
- Цифровизация технического и профессионального образования требует практико-ориентированных
  инструментов, доступных в любом кабинете с компьютером.
- Интернет вещей (IoT) и аппаратное обеспечение ПК входят в программы подготовки IT-специалистов,
  но лабораторная база обновляется медленно.
- Интеллектуальные помощники становятся частью обучения; важно использовать их безопасно,
  прозрачно и без передачи персональных данных.

## Целевая аудитория
- студенты колледжей (IT-специальности);
- школьники старших классов;
- начинающие IT-специалисты;
- преподаватели информатики и IT-дисциплин.

## Цель
Создать доступную веб-лабораторию, в которой учащийся безопасно отрабатывает сборку ПК и
создание простых IoT-систем, а AI-наставник объясняет ошибки и подсказывает следующий шаг.

## Задачи
1. Разработать симулятор сборки ПК с проверкой совместимости и имитацией POST.
2. Разработать симулятор IoT-систем на ESP32 с назначением GPIO и симуляцией датчиков.
3. Реализовать AI Mentor, который анализирует состояние лаборатории и даёт контекстные подсказки.
4. Ввести режимы «Обучение» и «Экзамен» и систему оценивания (100 баллов).
5. Сохранять прогресс учащегося и дать преподавателю сводку и экспорт результатов.
6. Обеспечить двуязычный интерфейс (русский и казахский).
7. Сделать проект бесплатным в размещении и работающим без интернета.

## Используемые технологии
- HTML5 (семантическая разметка, доступность), CSS3 (адаптивная тёмная тема), JavaScript ES6+ без библиотек;
- localStorage — хранение прогресса в браузере;
- SVG — схематичные изображения компонентов;
- GitHub Pages — бесплатный хостинг;
- опционально — LLM через собственный защищённый backend (параметр `AI_ENDPOINT`).

## Где используется искусственный интеллект
AI Mentor встроен в обе лаборатории и:
- анализирует действия учащегося (выбранное задание, установленные компоненты, подключения GPIO, результаты проверки);
- определяет ошибки (несовместимость сокета и памяти, недостаточная мощность БП, слабое охлаждение, неверный GPIO, отсутствующий компонент);
- формирует персонализированные подсказки с приоритетом: сначала критические ошибки, затем недостающие шаги;
- объясняет технические понятия (сокет, TDP, DDR4/DDR5, АЦП, input-only GPIO);
- предлагает следующий шаг.

**Честно о реализации:** базовая версия — локальная экспертная система (база правил диагностики),
работающая в браузере без отправки данных во внешние сервисы. Архитектура позволяет подключить
большую языковую модель через защищённый backend; при недоступности модели автоматически
используется локальная система.

## Практическая ценность
- Отработка навыков без затрат на оборудование и без риска его повредить.
- Подготовка к работе с реальными комплектующими и платами: учащийся приходит к оборудованию,
  уже понимая совместимость и правила подключения.
- Объективная оценка: баллы, ошибки, использованные подсказки, время.
- Преподаватель получает сводку и выгружает результаты в JSON/CSV.
- Режим «Демонстрация» позволяет быстро показать работу проекта.

## Новизна
- Сочетание двух лабораторий (аппаратное обеспечение ПК и IoT) с единым AI-наставником.
- Подсказки формируются по фактическому состоянию симулятора, а не по шаблону: наставник
  «примеряет» компонент к текущей сборке и объясняет причину несовместимости и способ исправления.
- Полностью офлайн-работа и отсутствие сбора персональных данных.
- Двуязычный интерфейс (русский/казахский) для системы образования Казахстана.

## Результат
Рабочий веб-сайт, который:
- открывается в любом современном браузере, в том числе без интернета;
- содержит 3 задания PC Builder и 3 проекта IoT Lab с автоматической проверкой;
- включает AI Mentor с четырьмя типами запросов;
- сохраняет прогресс и экспортирует результаты;
- публикуется бесплатно через GitHub Pages.

## Возможность масштабирования
- Новые комплектующие, задания и IoT-проекты добавляются как объекты данных в `pc-engine.js` и `iot-engine.js`.
- Новые языки — через объект переводов `translations.js`.
- Новые лаборатории (сети, серверы, кибергигиена) по той же архитектуре «движок + интерфейс + правила наставника».
- Подключение LLM и, при необходимости, централизованного хранения результатов через backend учебного заведения.

## Безопасность
- Нет регистрации и паролей.
- В коде нет API-ключей; ключи к внешнему AI допускается хранить только на сервере.
- Ошибки ученика не влияют на реальное оборудование.

## Защита данных
- ФИО учащихся не собираются; для экспорта можно указать необязательный псевдоним или номер.
- Прогресс хранится локально в браузере и удаляется кнопкой «Сбросить прогресс».
- Персональная информация не передаётся внешним AI-сервисам; при подключении LLM отправляется
  только техническое описание состояния лаборатории.
- AI — помощник, а не замена преподавателя; ответы рассматриваются как учебные рекомендации.

## Перспективы развития
- Подключение LLM для свободных вопросов ученика через защищённый сервер колледжа.
- Новые лаборатории: компьютерные сети, сборка серверов, программирование микроконтроллеров.
- Сценарии неисправностей для тренировки диагностики («ПК не включается — найдите причину»).
- Режим класса: выдача заданий и сбор результатов преподавателем.
- Перевод на английский язык и адаптация для инклюзивного обучения.
