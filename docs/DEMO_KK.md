# Конференциядағы қысқа көрсету реті

1. Алдын ала жергілікті нұсқаны іске қосып, браузерді ашып қойыңыз.
2. IoT Lab, ақылды жарықтандыру: ESP32, жарық датчигі, LED.
3. Датчик GPIO34, LED GPIO35: тексеру input-only қатесін көрсетеді. Көмекшіден себебін сұраңыз.
4. LED-ті GPIO12-ге ауыстырып, тексеріңіз. Симуляцияны іске қосыңыз.
5. 290 лк ON, 300 лк OFF, 310 лк OFF. Тоқтату және қайта іске қосу күйлерін көрсетіңіз.
6. «Менің прогресім» бөлімінен бір әрекеттің есебін ашыңыз. Қысқа дәлел жазып, JSON жүктеңіз.
7. Оқытушы режимінде JSON импортын көрсетіңіз. Бір файлды қайталап импорттау дубликат қоспайды.
8. Көмекшінің жергілікті ережелік жүйе екенін, оқу моделінің шектеулерін және нақты апробация күйін айтыңыз.

Демо режимінде нәтижелер прогреске жазылмайды. Журналды көрсету үшін қалыпты оқу режимін пайдаланыңыз. Емтиханда нәтиже тек аяқтау батырмасымен сақталады.

ПК үшін үйлесімді үлгі: Board A, Ryzen 5 5600G, Box Cooler, 8 GB DDR4, SSD 256 GB SATA, PSU 400 W. Кеңселік тапсырмада POST сәтті өтуі тиіс. Құрастырманы өзгертпей қайта іске қосу жаңа нәтиже қоспайды.
