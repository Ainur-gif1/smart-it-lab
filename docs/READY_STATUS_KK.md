# Дайын функциялар және қалған жұмыстар

## Кодта іске асқан және автоматты сынақпен тексерілген

- Бөлек жұмыс нұсқасы, бірден IoT Lab ашылады, қазақша негізгі тіл.
- Үш ПК және үш IoT тапсырмасы.
- IoT схемасын тексеру, іске қосу, тоқтату, жалғастыру және қайта іске қосу.
- ADC, input-only, қайталанған және жарамсыз GPIO тексеруі.
- Құрылымды өзгерткенде тексеруді, симуляцияны және ағымдағы нәтижені жою.
- 290/300/310 лк, 27/28/29 °C және қозғалыстың екі күйі.
- Ережелік контекстік көмекші. Емтиханда жауаптар мен дайын қадамдар жабық.
- Әрекет ID-і бойынша қайталанбайтын журнал, код және күнмен тіркеу.
- Есеп жобасы, JSON/CSV экспорт, тексерілген JSON импорт және дубликаттан қорғау.
- Браузерге сақтау бұғатталса, ағымдағы беттегі деректі сақтап, ескерту көрсету.
- Сабақ жоспары және пилоттың бос парағы.
- Python жергілікті сервері және 16 жергілікті ресурстың HTTP арқылы берілуі.

## Қолмен тексеру қажет

- Chrome/Edge/Firefox ішіндегі localhost және file:// іске қосу.
- Нақты батырма/пернетақта/сенсорлық әрекет, мобильді көрініс және accessibility.
- Браузер консолі, файл жүктеу диалогы, PDF баспасы және ұзын есептің беттелуі.
- Интернетті ажыратқандағы нақты браузер жұмысы.
- Оқу орнындағы студенттік апробация және нақты жабдыққа көшу.

Бұл тексерулер осы ортадағы preview қызметінің жоқтығына байланысты орындалды деп белгіленбеген. Автоматты DOM моделі браузерді алмастырмайды.

## Қазіргі шектеулер

Орталық сервер, аккаунт, LMS интеграциясы және қорғалған емтихан жоқ. Импортталған ортақ кесте тек ағымдағы бетте. Пайдаланушы нәтижелерді өзгерте алады. Модель нақты электрлік тізбектерді толық модельдемейді. Сыртқы LLM қосылмаған. Студенттік тиімділік статистикасы жиналмаған.
